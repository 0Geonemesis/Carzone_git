IMPORTANTE - DRIVER MySQL
==========================

Debes agregar el driver de MySQL manualmente:

1. Descarga "mysql-connector-j-8.0.33.jar" desde:
   https://dev.mysql.com/downloads/connector/j/
   o desde Maven: https://mvnrepository.com/artifact/com.mysql/mysql-connector-j/8.0.33

2. Copia el archivo .jar a esta carpeta: /lib/

3. En NetBeans, clic derecho en el proyecto → Properties → Libraries
   → Add JAR/Folder → selecciona el .jar descargado.

El proyecto ya está configurado para buscar:
   lib/mysql-connector-j-8.0.33.jar
